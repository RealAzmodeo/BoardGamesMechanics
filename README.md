# Board Game Mechanics Encyclopedia

## Project Goal

This project aims to create a comprehensive, structured database of board game mechanics. The goal is to:

*   **Identify and Collect:** Gather information on a wide array of game mechanics.
*   **Deconstruct and Analyze:** Break down mechanics into their core components and understand their underlying principles.
*   **Classify:** Categorize mechanics to understand their relationships and distinctions.
*   **Parameterize:** Identify variables that can modify or define a mechanic's behavior.
*   **Facilitate Understanding and Innovation:** Ultimately, enable a deeper understanding of game design, and provide a basis for combining, modifying, and creating new mechanics.

## Data Structure

Mechanic information is stored in JSON files within the `game_mechanics_data` directory. Each file represents a single game mechanic and adheres to a defined template (see `game_mechanics_data/mechanic_template.json`).

The key fields for each mechanic include:

*   `id`: A unique identifier for the mechanic.
*   `name`: The common name of the mechanic.
*   `description`: A detailed explanation of its workings.
*   `core_concepts`: Fundamental ideas or actions involved.
*   `parameters`: Variables that define or alter the mechanic.
*   `classification`: Its primary category.
*   `sub_classification`: More specific sub-categories.
*   `related_mechanics`: Links to other mechanics and the nature of their relationship.
*   `examples_in_games`: Notable board games that feature the mechanic.
*   `notes_on_combination_modification`: Insights into how the mechanic can be integrated with others or changed.
